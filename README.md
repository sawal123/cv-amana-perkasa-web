# CV AMANA PERKASA — Company Profile Website

Website company profile event service dengan Next.js, Tailwind CSS, dan Motion.

## Stack
- Next.js 16
- React 19
- Tailwind CSS 4
- Motion for React
- TypeScript

## Menjalankan
```bash
npm install
npm run dev
```
Buka `http://localhost:3000`.

## Build static
```bash
npm run build
```
Hasil static export berada di folder `out/` dan dapat di-host di Vercel, Netlify, Cloudflare Pages, atau hosting static biasa.

## Bagian yang paling mudah diedit
Edit `data/site.ts` untuk mengganti:
- Nama perusahaan / tagline
- Deskripsi company profile
- Kontak
- Layanan
- 10 portfolio project
- Struktur management / team
- Workflow

Ganti gambar project di `public/projects/` dan pertahankan nama file yang sama, atau ubah path pada `data/site.ts`.

## Catatan
Gambar portfolio saat ini merupakan visual konsep sementara yang dibuat untuk template company profile. Ganti dengan dokumentasi project asli sebelum publikasi/bidding resmi bila diperlukan.
